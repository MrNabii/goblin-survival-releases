# Goblin Survival

Кооперативная игра на выживание. Волны врагов, крафт, восемь классов гоблинов.

## Как играть

1. Скачай **GoblinSurvivalLauncher.exe** из [последнего релиза](../../releases/latest).
2. Запусти. Лаунчер сам скачает игру и будет держать её свежей.

Игра ставится в `%LOCALAPPDATA%\GoblinSurvival`, сохранения — в
`%USERPROFILE%\AppData\LocalLow\InvalidGaming\Goblin Survival`. Обновления
сохранения не трогают.

При первом запуске Windows может предупредить про неизвестного издателя:
сборка не подписана сертификатом. Жми «Подробнее» → «Выполнить в любом случае».

## Совместная игра

Один создаёт игру, остальные подключаются к его адресу. В локальной сети хост
находится сам, без ввода адреса.

**Версии должны совпадать.** Игрока с другой версией хост не пустит и скажет,
какая у кого — обнови игру через лаунчер.

## Что здесь лежит

Только сборки. Исходники — в закрытом репозитории.
